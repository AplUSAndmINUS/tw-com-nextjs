# 2026-11-18: One site nav on every page (#281)

Part B of the home rebuild (see `2026-11-18-home-rebuild.md`).

## Ask (Terence)

- Nav like the user copy: About, The Book, Content (dropdown; the Content
  link itself goes to /content-hub/), Contact; Display and Book a
  Conversation at the top; the same on mobile.
- "Every page now": not only the redesigned pages.

## What was built

- Brought the nav from the user-copy zip: `TwSiteNav` (DSM), `SiteNav`,
  `FixedSiteNav`, `src/lib/navMode.ts`, `SkipLink`, `BackLink`, the
  navigation and identity content, and text size in the Display panel
  (`fontScale.ts`, `FontScaleProvider`, `themeScript.ts`).
- Every DSM page renders `<SiteNav />`, which replaces its own `TwPageNav`
  (and the home page's `HomeNav`). The legacy-layout routes /podcasts and
  /unsubscribe get it in a fixed slot. Only /dsm-preview keeps the old Header.
- Book a Conversation opens the full-screen booking modal (#278) from the
  bar, the mobile menu and the mobile pill.
- Contact goes to `/#contact` until /contact/ is rebuilt.
- Detail pages get a back link: blog, portfolio, videos.
- Removed the dead per-page nav pieces and the old ConsultationStepper modal
  UI. Its data and helpers stay because BookingFlow uses them.
- The Ko-fi "Tip Me" button is hidden while the booking modal is open,
  because it stacked above the modal on phones.

## Left for later

- The zip's `layout.tsx` metadata change (`DEFAULT_DESCRIPTION`, `SITE_URL`)
  is identity/SEO work, not nav.
