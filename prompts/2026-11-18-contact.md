# 2026-11-18: /contact (#295)

## Ask (Terence)

"Literally how it looks on the user-copy is what I want there, with the
'Book a conversation' [button] to pull up the same modal like on the home
page. Right now, it has it within the page... it should just be a modal."

## What was built

- **The page:** the user copy's /contact (intro and jump list, Book a
  Conversation, Send a message, the newsletter, Find me online), built from
  the zip's `ContactForm`, `NewsletterForm`, `TwLinkStack`, `formErrors.ts`
  and `contactValidation.ts`.
- **Booking:** the inline `BookingFlow` is replaced by a `BookingTrigger`
  that opens the full-screen dialog (#278). The jump list's Book a
  Conversation opens it too (`ContactWaysIn`, plus an optional `onClick` on
  `TwLinkStackItem`). A `<noscript>` TidyCal link covers visitors without
  JavaScript.
- **Links:** Contact, message and newsletter links across the site now point
  at /contact. The footer keeps the #newsletter anchor only on Home, so ids
  stay unique.
- **Kept from develop:** the metadata block (the zip's `pageMetadata` helper
  doesn't exist here). `getContactPageSchema` was added from the zip.
